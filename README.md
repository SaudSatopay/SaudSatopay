## 👋 About Me

I'm **Saud Satopay** — a full-stack developer and AI/ML engineer who likes turning hard problems into things people can actually use. I build production-grade web and mobile apps, and design ML systems spanning **RAG**, **on-device computer vision**, and **applied data science**. A lot of what you'll find here started life at a hackathon and kept on going.

- 🧠 **Applied AI/ML** — RAG pipelines, hybrid retrieval, on-device vision, LLM-powered apps
- 🌐 **Full-stack web** — Next.js, React, TypeScript, Supabase
- 📱 **Mobile** — React Native / Expo &amp; Flutter
- 📊 **Data science** — turning 200k+ rows of mess into clear decisions
- 🏆 **Hackathons** — ship fast, learn faster, occasionally take home the win
- ⚡ Always up for a good problem and a clean solution
